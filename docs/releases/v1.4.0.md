# Styled Dock v1.4.0

Click a dock icon with multiple windows to open a picker with live previews.
Click a preview to focus that window or restore it if minimized.

- Use the arrow keys and Enter to select a window, or Escape to dismiss the picker.
- The picker labels active and minimized windows. Each card shows the window
  title, with an app icon available when Windows cannot provide a preview.

## Download and upgrade

Download **styled-dock.exe**, or extract **Styled-Dock-v1.4.0-windows-x64.zip**
for the executable, documentation, and example config. Use **SHA256SUMS.txt**
to verify the files. The executable is unsigned.

Quit the previous version before replacing its executable. Keep your current
`config.toml` to retain settings and pins.
