# Styled Dock v1.3.0

This release refines the dock and menu bar, groups everyday controls in a smaller
Quick Settings panel, and makes Light and Dark mode more consistent.

## Changes

- The dock uses a neutral shelf, small running-app dots, and one divider before
  Downloads and Recycle Bin. Window counts are available in tooltips and menus.
- The slimmer menu bar puts a text-only clock at the far right. A compact input
  indicator shows the current language and opens a keyboard-layout picker.
  Hover over the indicator for the full layout name.
- Quick Settings groups Wi-Fi and Bluetooth and provides independent volume
  and brightness sliders. Brightness appears on supported displays.
- The Network panel distinguishes Ethernet, Wi-Fi, and cellular status and
  groups Mobile hotspot with the connection controls.
- Settings → Appearance groups Auto (Windows), Light, Dark, dock size, hover
  zoom, and opacity. These controls preview live, and Cancel restores the saved
  appearance. Advanced contains exact sizes, spacing, and animation timing.
- Tray mirroring is off by default. Explicit preferences in existing
  configurations are respected.

## Download and upgrade

Download **styled-dock.exe**, or extract **Styled-Dock-v1.3.0-windows-x64.zip**
for the executable, documentation, and example config. Use **SHA256SUMS.txt**
to verify the files. The executable is unsigned.

Quit the previous version before replacing its executable. Keep your current
`config.toml` to retain settings and pins. The ZIP includes an example config.

## Known limits

The Windows work-area reservation issue can still occur with tray mirroring
and reserve-space mode. The fullscreen desktop diagnostic reproduced it with
both v1.2.0 and v1.3.0. Brightness and Mobile hotspot availability depend on
the display, network hardware, and Windows configuration.
