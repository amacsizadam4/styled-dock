# Styled Dock v1.2.0

Desktop recovery improvements, keyboard and accessibility support, live Settings
previews, and Mobile hotspot controls.

## Changes

- Recover desktop state after resume even with the top bar disabled, coalesce
  recovery notifications, handle stale monitor handles, and release taskbar hiding
  on displays the dock no longer owns.
- Bound cross-process tray forwarding waits and handle reentrant notifications.
  Tray mirroring remains experimental.
- Add Mobile hotspot status, a toggle, and Windows settings links to Quick
  Settings and the Wi-Fi panel, using a shared state cache and availability reasons.
- Add native UI Automation/MSAA button providers, keyboard navigation for dock
  and status-bar controls, predictable focus return, and per-window close commands.
  Ctrl+Alt+F focuses the dock; Ctrl+Alt+B focuses the top bar.
- Preview size, zoom, motion, and opacity changes live in Settings. Cancel restores
  the prior appearance. Improve invalid-field focus and add Save a copy recovery
  plus a clickable active-config path.
- Add Styled Dock's own notification icon with Settings, Restore taskbar, and Quit.
- Improve menu sizing, full-label tooltips, and native menu fallback for oversized
  panels and high contrast.
- Add a desktop diagnostic and detailed validation records. The roadmap now plans
  moving the Windows input-language/layout switcher from the dock to the top bar;
  that move is not implemented in this release.

## Download and upgrade

Download **styled-dock.exe**, or extract **Styled-Dock-v1.2.0-windows-x64.zip**
for the executable, documentation, and example config. Verify downloads against
**SHA256SUMS.txt**. The executable is unsigned.

Quit the old dock before replacing its executable and keep your existing config.
The ZIP includes `config.example.toml`, not an active config. New installations
use first-time setup and `%LOCALAPPDATA%\StyledDock\config.toml`; existing portable
configs retain priority. Keep the executable in its final location before enabling
Windows startup; disable and re-enable startup if you move it.

## Validation and remaining limits

- Release preparation on 2026-11-19: Windows x64 release build, formatting,
  full test compilation, desktop diagnostic build, and all 13 CI-selected tests
  passed. The running dock was left in place; the full native desktop suite was
  not rerun during release preparation.
- Earlier implementation validation recorded two final full serial passes, each
  with **46 passed, zero failed, two ignored visual helpers**, plus seven isolated
  smoke scenarios at 125% scale. See [the phase-3 record](../usability-accessibility.md)
  and [desktop validation](../desktop-validation.md) for scope and earlier failures.
- Actual hotspot enable/disable, Narrator/NVDA workflows, real pointer gestures,
  the complete high-contrast/DPI matrix, physical sleep and monitor changes,
  Explorer restart, and long-session behavior still need verification. Phases 2
  and 3 remain open; this release does not establish complete taskbar replacement
  or universal tray compatibility.
